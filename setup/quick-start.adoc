= NetApp Workload Factory 快速入门
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
用户可以作为云数据服务从 NetApp Console 访问 NetApp Workload Factory。通过在 NetApp Console 中注册并创建帐户，以及添加云提供商凭据，开始使用 Workload Factory，以便 Workload Factory 可以直接管理您的资源并优化您的工作负载。

在开始之前，您应该了解 link:learn-about-workload-factory.html["Workload Factory"]。
