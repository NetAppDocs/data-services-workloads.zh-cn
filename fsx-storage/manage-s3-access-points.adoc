= 在 NetApp Workload Factory 中管理卷的 S3 访问点
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
更新 NetApp Workload Factory 中卷的 S3 访问点详细信息或删除 S3 访问点。

您还可以启用或禁用接入点的*库存表*。库存表会为 S3 接入点可访问的所有对象生成元数据，并产生 AWS S3 请求成本。有关详细信息，请参见link:https://aws.amazon.com/s3/pricing/["Amazon S3 定价文档"^]。



[[edit-the-s3-access-points-for-a-volume]]
== 编辑卷的 S3 访问点

在 NetApp Workload Factory 中编辑卷的 S3 访问点。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *Storage* > *Volumes explorer*。
. 选择要编辑其 S3 接入点的卷的操作菜单，然后选择 *Advanced actions*，然后选择 *Manage S3 access points*。
. 在*管理 S3 接入点*屏幕中，选择操作菜单，然后选择*编辑接入点*。
. 进行更新，然后选择 *Apply*。
+
要为日志表功能设置基础架构，您必须选择 *Internet* 作为 S3 访问端点的网络配置。link:setup-journal-table.html["了解如何为 NetApp Workload Factory 设置日志表基础结构"]。





[[view-s3-access-point-details-for-a-volume]]
== 查看卷的 S3 访问点详细信息

查看 S3 接入点详细信息，如别名、ARN 和 S3 URI。启用库存和日记表后，您可以查看跨 S3 访问点的用户访问事件和对象操作的元数据和审计日志。

.关于此任务
当在卷上启用清单表时，您可以查看连接到卷的现有 S3 访问点的访问点、清单表和表存储桶详细信息。系统还提供到 AWS Management Console 中清单表的链接。

启用日志表后，Workload Factory 将在表中的访问点上生成日志供您参考。该表包括 CloudTrail 事件、跟踪（AWS 活动的记录）、CloudTrail 过滤器、CloudWatch 日志组等。

您可以复制访问点详细信息以用于其他应用程序。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *Storage* > *Volumes explorer*。
. 选择要查看其详细信息的卷的操作菜单，然后选择*高级操作*，然后选择*查看详细信息*。
+
详细信息显示在四个选项卡下：*Access point*、*Inventory table*、*Journal table* 和 *Table bucket*。

. 如果已启用库存或日记帐表的状态，但缺少 `get:Object`权限，请按照对话框中的说明添加所需的权限。
. 当日记账表状态为挂起时，您必须提供 CloudTrail ARN 才能将日记账表连接到创建的基础设施。按照说明使用 AWS CLI 或 AWS 管理控制台部署 CloudFormation 堆栈，然后返回 Workload Factory 控制台输入 CloudTrail ARN。




[[delete-the-s3-access-points-for-a-volume-in-netapp-workload-factory]]
== 删除 NetApp Workload Factory 中卷的 S3 访问点

从 NetApp Workload Factory 中的卷删除现有 S3 访问点。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *Storage* > *Volumes explorer*。
. 选择要为其管理 S3 接入点的卷的操作菜单，然后选择 *Advanced actions*，然后选择 *Manage S3 access points*。
. 选择要删除的 S3 接入点的操作菜单，然后选择 *Delete*。
. 在*删除 S3 接入点*对话框中，选择*删除*以从卷中删除 S3 接入点。
+
Workload Factory 不会删除库存或日记表，但您可以从 AWS 管理控制台手动删除它们。
