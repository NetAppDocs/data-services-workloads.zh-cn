= 在 NetApp Workload Factory 中管理 Storage VM 设置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 NetApp Workload Factory 中管理存储虚拟机的设置。您可以为存储虚拟机配置和更新 Active Directory，可以更新存储虚拟机密码，并管理存储虚拟机的标签。



[[configure-and-update-ad-for-a-storage-vm-in-netapp-workload-factory]]
== 在 NetApp Workload Factory 中为存储 VM 配置和更新 AD

在 NetApp Workload Factory 中为 FSx for ONTAP 文件系统中的存储虚拟机配置和更新 Active Directory。

相同的步骤适用于为存储 VM 配置和更新 Active Directory。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *Storage* > *FSx for ONTAP*。
. 从 *FSx for ONTAP* 中，选择包含要更新的存储 VM 的文件系统的操作菜单，然后选择 *管理*。
. 在 Storage VMs 下的文件系统概述中，选择 *Manage*。
. 在 Manage storage VMs （管理存储虚拟机）屏幕中，选择要配置 Active Directory 的存储虚拟机的操作菜单，然后选择 *Basic actions （基本操作）* > *Manage AD configuration （管理AD配置）*。
. 在“管理 AD 配置”页面上，提供以下内容：
+
.. *要加入的 Active Directory 域*：输入 Active Directory 的完全限定域名（FQDN）。
.. *DNS IP 地址*：请输入最多三个 IP 地址（以逗号分隔）。
.. *SMB 服务器 NetBIOS 名称*：输入要为存储 VM 创建的 Active Directory 计算机对象的 SMB 服务器 NetBIOS 名称。这是 Active Directory 中此 SVM 的名称。
.. *用户名*：输入现有 Active Directory 中服务帐户的用户名。
+
请勿包含域前缀或后缀。对于 `EXAMPLE\ADMIN`，请使用 `ADMIN`。

.. *密码*：输入服务帐户的密码。
.. *组织单位 (OU)*：输入组织单位。
+
OU 是您要加入文件系统的组织单位的可分辨路径名。

.. *委派管理员组*：（可选）输入委派的文件系统管理员组。
+
委派的管理员组是 Active Directory 中可以管理文件系统的组的名称。

+
如果您使用的是 AWS Managed Microsoft AD，则必须指定一个组，例如 AWS Delegated FSx Administrators、AWS Delegated Administrators 或对 OU 具有委派权限的自定义组。

+
如果要连接到自我管理的 AD，请使用 AD 中组的名称。默认组是 `Domain Admins`。



. 选择*应用*。




[[manage-storage-vm-tags]]
== 管理 storage VM 标记

标签可以帮助您对资源进行分类。您可以随时在 NetApp Workload Factory 中添加、编辑和删除存储虚拟机的标签。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *Storage* > *FSx for ONTAP*。
. 从 *FSx for ONTAP* 中，选择包含要更新的存储 VM 的文件系统的操作菜单，然后选择 *管理*。
. 在 Storage VMs 下的文件系统概述中，选择 *Manage*。
. 在 Manage storage VMs（管理存储虚拟机）屏幕中，选择要编辑标签的存储虚拟机的操作菜单，然后选择 *Basic actions（基本操作）* > *Edit storage VM tags（编辑存储虚拟机标签）*。
. 在“编辑存储 VM 标记”页面上，添加、编辑或删除标记。
+
可以应用于存储虚拟机的标签数上限为 50 个。

. 选择*应用*。




[[reset-the-storage-vm-password-in-netapp-workload-factory]]
== 在 NetApp Workload Factory 中重置 storage VM 密码

必要时在 NetApp Workload Factory 中重置 Storage VM 的密码。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *Storage* > *FSx for ONTAP*。
. 从 *FSx for ONTAP* 中，选择要重置存储 VM 密码的文件系统的操作菜单，然后选择 *管理*。
. 在 Storage VMs 下的文件系统概述中，选择 *Manage*。
. 在 Manage storage VMs（管理存储虚拟机）屏幕中，选择要重置密码的存储虚拟机的操作菜单，然后选择 *Basic actions*（基本操作） > *Reset password*（重置密码）。
. 在“重置密码”对话框中，提供以下内容：
+
.. *新密码*：输入存储 VM 的新密码。
.. *确认密码*：再次输入新密码进行确认。
