= 使用网络保管库保护您的 FSx for ONTAP 数据
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
网络保管库卷是一个隔离的安全存储位置，用于存储数据的备份副本，以保护其免受勒索软件攻击和其他网络威胁。作为保管库创建的一部分，您将创建一个网络保管库卷，禁用所有客户端协议，并在源卷和网络保管库卷之间设置复制关系，并在网络保管库卷上创建不可变的快照。

.什么是网络保管库？
网络保管库是一种特定的数据保护技术，涉及将关键数据存储在与主要 IT 基础架构分开的隔离环境中。

网络保管库是一个“气隙”、不可变和不可擦除的数据存储库，可以免受影响主网络的威胁，例如恶意软件、勒索软件甚至内部威胁。可以使用不可变和不可擦除的快照来实现网络保管库。

采用传统方法的物理隔离备份涉及创建空间并将主介质和辅助介质进行物理分离。通过将介质转移到异地和/或切断连接，恶意行为者将无法访问数据。这可以保护数据，但可能会导致恢复时间变慢。

.FSx for ONTAP 网络保险库
Amazon FSx for NetApp ONTAP 支持作为网络保管库源和目标。

.实施
Workload Factory 为创建网络保管库架构提供帮助。在您联系 NetApp 表示有兴趣实施网络保管库后，NetApp 专员会与您联系，讨论您的要求。

请发送电子邮件至 ng-FSx-CyberVault@netapp.com 以开始使用。
