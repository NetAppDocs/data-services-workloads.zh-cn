= 在 NetApp Workload Factory 中删除 storage VM
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从 FSx for ONTAP 文件系统配置中删除不再需要的存储 VM（SVM）。

.开始之前
在删除 storage VM 之前，请查看以下内容：

* 确保没有应用程序正在访问 SVM 中的数据。
* 删除连接到此 SVM 的所有非根卷。


.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *Storage* > *FSx for ONTAP*。
. 从 *FSx for ONTAP* 中，选择要更新的文件系统的操作菜单，然后选择*管理*。
. 在 Storage VMs 下的文件系统概述中，选择 *Manage*。
. 在“管理存储 VM”屏幕上，选择要删除的存储 VM 的操作菜单。
. 选择*删除 storage VM*。
. 在 Delete storage VM 对话框中，键入“delete”以删除 storage VM。
. 选择*删除*以确认。
