= 部署建议的 FSx for ONTAP 文件系统
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在验证推荐的 FSx for ONTAP 文件系统（或在某些情况下为多个文件系统）符合您的确切要求后，您可以使用 Workload Factory 在您的 AWS 环境中部署该系统。

按照 link:../fsx-storage/create-discover-systems.html["在 NetApp Workload Factory 中创建 FSx for ONTAP 文件系统"^] 中的说明，根据 Workload Factory 建议的配置部署 FSx for ONTAP 文件系统。您可以使用说明中的 *高级创建* 步骤来完全自定义文件系统。
