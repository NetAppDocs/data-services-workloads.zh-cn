= 在迁移到 VMware Cloud with VMware 工作负载之前捕获 VM 配置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用迁移顾问虚拟机收集器脚本或 RVTools 捕获当前虚拟机配置。我们建议您使用迁移顾问虚拟机收集器脚本，因为它会收集虚拟机配置和性能数据，以制定最准确的计划。

[role="tabbed-block"]
====
.使用 Migration advisor VM 收集器脚本
--
NetApp 迁移顾问虚拟机收集器脚本从您的 vCenter 收集虚拟机配置信息，类似于 RVTools 收集的信息，但是，它会捕获当前虚拟机性能数据，以提供实际的读取和写入 IOPS 和吞吐量统计信息。

您需要启动 Migration advisor，以便从 Codebox 窗口复制 Migration advisor VM 收集器脚本。

.开始之前
运行收集器脚本的系统必须满足以下要求：

* 必须安装 Microsoft PowerShell 7.0 或更高版本。如果需要安装 PowerShell，请参阅 https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell?view=powershell-7.4["Microsoft PowerShell 文档"^]。
* 必须安装 VMware PowerCLI。如果需要安装 PowerCLI，请参阅 https://docs.vmware.com/en/VMware-vSphere/7.0/com.vmware.esxi.install.doc/GUID-F02D0C2D-B226-4908-9E5C-2E783D41FE2D.html["VMware PowerCLI 文档"^]。
* 必须禁用 SSL 证书检查。
* PowerShell 必须允许运行未签名的脚本。


请注意，如果您计划从虚拟机捕获长期统计数据（每日统计数据），则必须在 vSphere 管理控制台（VMware 管理环境）中激活统计数据级别 3 或更高级别。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *VMware*。
+
此时将显示规划中心。

. 在 VMware 菜单中，选择 *评估和计划*，然后选择 *迁移到 VMware Cloud on AWS*。
+
此时将显示 VMware 迁移顾问主页。

. 选择*计划并创建 VMC*。
. 选择*让我们开始吧！*。您可以通过选中复选框选择不再显示此页面。
. 选择*创建新的部署计划*，为*使用迁移顾问 VMware 数据收集器*选择相应选项，然后选择*下一步*。
+
此时将显示 *Prepare for VMware Cloud on AWS migration* 页面。

. 在 Codebox 窗口中，选择 image:button-download-codebox.png["“下载”按钮"] 将 Migration advisor VM 收集器脚本（名为“list-vms.ps1”）保存到目标系统，或选择 image:button-copy-codebox.png["“复制”按钮"] 复制该脚本，以便将其粘贴到相应的系统上。
. 按照下面的步骤捕获当前虚拟机的配置：
+
.. 登录到您下载了数据收集器且已安装 PowerShell 和 PowerCLI 的系统。
.. 通过运行以下命令连接到 VMware vCenter 服务器：
+
[source, console]
----
Connect-VIServer -server <server_IP>
----
+
将 <server_IP> 替换为您 VMware 服务器的 IP 地址或主机名。

.. 运行您下载的数据收集器脚本，并为“每日”或“每小时” VM 统计信息指定数据收集选项。
+
[source, console]
----
./list-vms.ps1 -isLongTermDataCollectionEnabled <true | false>
----
+
其中：

+
*** *true* 以 5 分钟为间隔收集过去 24 小时的 IOPS 和吞吐量数据
*** *false* 以 20 秒的间隔收集过去 1 小时的 IOPS 和吞吐量数据。






.结果
该脚本在当前工作目录中输出一个名为 `list-vms-yyyy-MM-dd-HH-mm-ss.csv`的 CSV 文件。该 CSV 文件包含所有 VM 及其属性的列表，以及它们的 IOPS 和吞吐量数据。

--
.使用 RVTools 软件
--
RVTools 是一个 Windows 应用程序，可与 VCenter 和 ESX 服务器（5.x 至 8.0）交互以捕获有关 VMware 虚拟环境的信息。它收集有关虚拟机、CPU、内存、磁盘、群集、ESX 主机、数据存储等信息。您可以将此信息导出到 xlsx 文件以用于迁移顾问。

link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["详细了解 RVTools"^]

.步骤
. 在 link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["RVTools 网站"^] 中下载并安装 RVTools 4.4.2 或更高版本
. 启动 RVTools 并登录到目标 VCenter Server。
+
这将捕获有关该 VCenter Server 的信息。

. 将您的 VMware 信息导出到 xlsx 或 xls 文件。
+
有关详细信息，请参见 link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["“资源”部分中的 RVTools 文档"^] 中的“命令行参数”一章。



.结果
包含结果的 xlsx 或 xls 文件将保存到您的工作目录。
