= 使用迁移顾问创建 Amazon EVS 部署计划
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从 VMware 规划中心，您可以启动 Amazon EVS 迁移顾问，以帮助创建根据您的需求定制的迁移计划。

您可以创建部署计划，将虚拟机迁移到 Amazon Elastic VMware Service，并将定制的 Amazon FSx for NetApp ONTAP 文件系统用作外部数据存储。迁移顾问中的选项可能因用于收集虚拟机清单数据的工具而异。



[[requirements]]
== 要求

* 您必须拥有用户名和密码才能访问 Workload Factory。如果您没有访问权限，请立即创建账号。查看说明 link:quick-start-vmware.html["此处"]。
* 您必须具有 Amazon Elastic VMware Service 订阅。




[[steps]]
== 步骤

. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航到 Workloads，即 Workload Factory 的菜单项"]，*Workloads* > *VMware*。
+
此时将显示规划中心。

. 从列表中选择要用于制定部署计划的 VM 清单，然后选择该行中的 *开始计划*。
. 从显示的下拉菜单中选择 *EVS*。
+
此时将显示 *Prepare for AWS Cloud onboarding* 向导。

. 输入所需信息。


[discrete]
===== 指定

. 在 _VM configuration upload_ 部分中，查看有关用于创建迁移计划的数据集的信息。*虚拟机清单摘要* 部分根据清单文件进行填充，以反映虚拟机的数量和总存储容量。
. 在 _VM 库存注意事项_ 部分中，选择用于筛选要迁移的 VM 列表的选项：
+
.. *区域*：选择将部署 Amazon FSx for NetApp ONTAP 文件系统的区域。为了获得最佳性能和成本效益，此区域通常与部署现有 Amazon EC2 SDDC 的区域相同。
.. 选择此区域中 VM 的预测性能级别。我们建议您从较小的 IOPS 设置开始。随着工作负载的迁移或部署，您可以在创建文件系统后增加已调配的 SSD IOPS：
+
*** *标准到高性能*：适用于平均 IO 速率在 20 到 5000 IOPS 之间的虚拟机。
*** *非常高的性能*：适用于平均 IO 速率超过 5000 IOPS 的虚拟机。
*** *性能非常低*：适用于平均 IO 速率低于 20 IOPS 的虚拟机。




. 在_目标容量和保护注意事项_部分，从几个存储选项中进行选择：
+
.. *要考虑的虚拟机存储*：选择为每个接入的虚拟机创建的数据存储是根据其当前使用的大小（推荐）还是其配置的大小来确定容量。
+
外部数据存储将使用 Amazon FSx for NetApp ONTAP 文件系统卷来实现。

.. *平均数据缩减率*：从三种常见数据缩减率中选择。选择“1:1 - 无缩减”、“1:1.25 - 缩减 20%”或“1:1.5 - 缩减 33%”。
+
如果您不确定选择哪个比例，请选择 *帮助我决定*。此时将显示 _Data reduction ratio assistant_ 对话框。选择适用于您的 VM 清单和存储资产的任何语句。该助手将推荐合适的数据缩减率。选择 *应用* 以使用推荐的比例。

.. *余量百分比*：输入添加到您的 FSx for ONTAP 文件系统容量中的容量增长百分比。
+
请注意，如果选择的数量小于 20%，您将无法创建用于保护和长期备份的卷快照。

.. *虚拟机快照保护*：启用此选项可使用快照保护虚拟机。


. 选择 *Next*。


[discrete]
===== 选择

. 在*选择虚拟机*页面上，从列表中选择要包含在 AWS 迁移中的虚拟机。您可以按每个虚拟机的电源状态以及虚拟机所在的数据中心和群集筛选列表。
+
在虚拟机列表中，您可以选择要显示为列的虚拟机信息类型。例如，选择 _峰值读取 IOPS_ 将显示一列，其中包含每个虚拟机的峰值读取 IOPS。

. （可选）您可以选择针对成本或可恢复性优化部署。
+
** *成本*：Workload Factory 从列表中选择 I/O 密度较低的虚拟机。这有助于减少资源需求。
** *可恢复性*：Workload Factory 从列表中选择最容易在本地快速复制的虚拟机。这可以在发生中断时提供快速恢复时间。


. 选择 *Next*。


[discrete]
===== 设计

* 在*ClassReview 实例存储分配*页面上，查看 VM 信息、卷分类规则、卷分配以及将作为部署的一部分进行迁移的卷列表，然后选择*下一步*。


[discrete]
===== 查看计划

. 在*审核计划*页面上，查看您计划迁移的所有虚拟机的预计每月节省金额和成本估算。
+
页面顶部估算了 FSx for ONTAP 文件系统和 EBS 卷的每月节省费用。您可以展开每个部分，查看建议的文件系统配置、估算的节省明细、假设和技术免责声明的详细信息。

+
默认情况下，迁移计划会自动保存在规划中心的计划列表中。

. 您可以选择将迁移计划导出为 PDF 或 CSV 文件，方法是选择页面右上角的 *管理计划*，然后选择 *下载报告（.pdf）* 或 *下载虚拟机存储部署（.csv）*。
+
.csv 文件创建了迁移计划中包含的所有虚拟机及其分配的存储卷的映射。

. 当您准备好继续计划时，选择 *Provision* 以开始部署推荐的 Amazon FSx for NetApp ONTAP 文件系统。


link:deploy-fsx-file-system-evs.html["部署 VMware 工作负载推荐的 FSx for ONTAP 文件系统"]。
