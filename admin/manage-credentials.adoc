= 从 NetApp Workload Factory 中删除凭据
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
如果您不再需要一组凭据，则可以从 Workload Factory 中将其删除。您只能删除未与 FSx for ONTAP 文件系统关联的凭据。

.步骤
. 登录到 link:https://console.netapp.com["NetApp Console"^]。
. 从 NetApp Console 菜单中，选择 *工作负载* > *管理* > *凭据*。
. 在*凭据*页面上，执行以下操作：
+
** 在 Workload Factory 控制台中，选择一组凭据的操作菜单，然后选择*移除*。选择*移除*以确认。
** 在 NetApp Console 中，选择一组凭据的操作菜单，然后选择*删除*。选择*删除*以确认。
